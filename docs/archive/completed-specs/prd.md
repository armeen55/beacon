# Beacon PRD

## What Beacon is
Beacon is a premium search visibility command center for operators managing SEO and AI search visibility.

It is built to answer:
- What matters most right now?
- Where are the biggest opportunities?
- What exact changes should be made?
- What has already shipped?
- What actually worked?
- What are competitors doing better or worse?
- What foundational coverage gaps still exist?

## Initial mode
Beacon is currently a single-user, single-workspace internal product.
No auth, billing, teams, or external integrations yet.

## Core modules
- Dashboard
- Opportunities
- Briefs
- Changelog
- Results
- Competitors
- Coverage
- Weekly Summary

## Product principles
- Workflow over dashboards
- Attribution over vanity metrics
- Actionability over raw data
- Premium operator UX
- Production-shaped architecture
